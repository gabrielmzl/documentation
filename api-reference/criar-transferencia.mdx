## Visão Geral

Este endpoint permite criar uma transferência PIX para qualquer chave PIX cadastrada no sistema brasileiro de pagamentos.

<Warning>
  Caso o campo `document` seja informado, será possível apenas realizar a
  transação para o CPF/CNPJ especificado. Se a transação for efetuada para uma
  chave PIX de outro documento, será enviado um webhook com o status `FAILED`.
</Warning>

## Autenticação

<ParamField header="Authorization" type="string" required>
  Token Bearer obtido no endpoint de autenticação ``` Bearer
  eyJhbGciOiJIUzI1NiIsInR5cCI6Ikp... ```
</ParamField>

<ParamField header="x-idempotency-key" type="string" required>
  Código único de idempotência para evitar transferências duplicadas
  
  **Importante:** Deve ser um UUID válido no formato `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`. Use um UUID único para cada operação.
</ParamField>

## Parâmetros do Body

<ParamField body="type" type="string" required default="pix_key">
  Tipo de transferência. Por enquanto, apenas `pix_key` é suportado
</ParamField>

<ParamField body="description" type="string" required>
  Descrição da transferência Exemplo: "Pagamento a fornecedor"
</ParamField>

<ParamField body="amount" type="string" required>
  Valor da transferência em centavos (500 = R$ 5,00) **Nota:** Enviado como
  string, não número
</ParamField>

<ParamField body="details" type="object" required>
  Detalhes do destinatário
  
  <Expandable title="Campos do details">
    <ParamField body="details.name" type="string" required>
      Nome completo do recebedor
    </ParamField>
    
    <ParamField body="details.document" type="string" required>
      CPF ou CNPJ do recebedor (apenas números)
    </ParamField>
    
    <ParamField body="details.key" type="string" required>
      Chave PIX do recebedor (pode ser CPF, CNPJ, e-mail, telefone ou chave aleatória)
    </ParamField>

    <ParamField body="details.keyType" type="string" required>
      Tipo da chave PIX do recebedor (pode ser CPF, CNPJ, EMAIL, PHONE ou EVP)
    </ParamField>

  </Expandable>
</ParamField>

```python Python
import requests
import uuid

headers = {
    'Authorization': f'Bearer {token}',
    'Content-Type': 'application/json',
    'x-idempotency-key': str(uuid.uuid4())
}

payload = {
    'type': 'pix_key',
    'description': 'Pagamento a fornecedor',
    'amount': '500',
    'details': {
        'name': 'João Silva',
        'document': '12345678900',
        'key': 'joao@example.com'
    }
}

response = requests.post(
    'https://api.pronttus.com.br/v1/banking/cash-out/pix',
    headers=headers,
    json=payload
)

data = response.json()
```

## Campos da Resposta

<ResponseField name="transactionId" type="string">
  UUID único da transação gerada
</ResponseField>

<ResponseField name="amount" type="integer">
  Valor da transferência em centavos
</ResponseField>

<ResponseField name="status" type="string">
  Status da transação: `PROCESSING`, `COMPLETED`, `FAILED`
</ResponseField>

<ResponseField name="createdAt" type="string">
  Data e hora de criação da transferência (ISO 8601)
</ResponseField>

<ResponseField name="x-idempotency-key" type="string">
  Chave de idempotência utilizada
</ResponseField>

## Tipos de Chave PIX Aceitos

| Tipo      | Formato            | Exemplo                                |
| --------- | ------------------ | -------------------------------------- |
| CPF       | 11 dígitos         | `12345678900`                          |
| CNPJ      | 14 dígitos         | `12345678000190`                       |
| E-mail    | E-mail válido      | `joao@example.com`                     |
| Telefone  | +55 + DDD + número | `+5511999999999`                       |
| Aleatória | UUID               | `a1b2c3d4-e5f6-7890-g1h2-i3j4k5l6m7n8` |
