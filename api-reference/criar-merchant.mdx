## Visão Geral

Este endpoint permite criar um novo merchant (subconta gráfica) para organizar recebimentos.

<Info>
  Para entender melhor o conceito de merchants e casos de uso, consulte a [documentação conceitual](/merchants).
</Info>

## Autenticação

<ParamField header="Authorization" type="string" required>
  Token Bearer obtido no endpoint de autenticação ``` Bearer
  eyJhbGciOiJIUzI1NiIsInR5cCI6Ikp... ```
</ParamField>

## Parâmetros do Body

<ParamField body="name" type="string" required>
  Nome do merchant (ex: "João da Silva")
</ParamField>

<ParamField body="document" type="string" required>
  CPF ou CNPJ do merchant (apenas números)
</ParamField>

<ParamField body="document_type" type="string" required>
  Tipo do documento: `CPF` ou `CNPJ`
</ParamField>

<ParamField body="email" type="string" required>
  E-mail do merchant
</ParamField>

<ParamField body="phone" type="string" required>
  Telefone do merchant com DDD (apenas números)
</ParamField>

```javascript JavaScript
const api = new PronttusAPI(clientId, clientSecret);

const response = await api.makeRequest(
  "https://api.pronttus.com.br/v1/merchants",
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      name: "João da Silva",
      document: "12345678901",
      document_type: "CPF",
      email: "joao@email.com",
      phone: "11999999999"
    }),
  }
);

const data = await response.json();

// Acessar dados do merchant criado
const merchant = data.data.merchant;
const walletId = data.data.wallet_id;
const credentials = data.data.credentials;

console.log('Wallet ID:', walletId);
console.log('Client ID:', credentials.client_id);
```

```python Python
import requests

headers = {
    'Authorization': f'Bearer {token}',
    'Content-Type': 'application/json'
}

payload = {
    'name': 'João da Silva',
    'document': '12345678901',
    'document_type': 'CPF',
    'email': 'joao@email.com',
    'phone': '11999999999'
}

response = requests.post(
    'https://api.pronttus.com.br/v1/merchants',
    headers=headers,
    json=payload
)

data = response.json()

# Acessar dados do merchant criado
merchant = data['data']['merchant']
wallet_id = data['data']['wallet_id']
credentials = data['data']['credentials']

print(f'Merchant criado: {merchant["name"]}')
print(f'Wallet ID: {wallet_id}')
print(f'Client ID: {credentials["client_id"]}')
```

## Informações Importantes

### Wallet ID
O `wallet_id` retornado é o identificador da carteira principal do merchant. Este ID é usado para:
- Configurar splits nas transações
- Consultar saldo específico da wallet
- Realizar transferências para/da wallet

### Credenciais do Merchant
Cada merchant criado recebe suas próprias credenciais de API:
- **client_id**: Identificador único do merchant
- **client_secret**: Chave secreta para autenticação

<Info>
  As credenciais do merchant são diferentes das credenciais da conta principal e devem ser usadas para operações específicas deste merchant.
</Info>

### Status do Merchant
O merchant é criado com status `ACTIVE` por padrão, permitindo:
- Receber splits de transações
- Realizar operações normalmente
- Acessar sua wallet
