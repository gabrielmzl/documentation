title: "Listar Merchants"
api: "GET https://api.pronttus.com.br/v1/merchants"
description: "Lista todos os merchants com paginação"
---

## Visão Geral

Este endpoint permite listar todos os merchants criados na sua conta com suporte a paginação e filtros.

## Autenticação

<ParamField header="Authorization" type="string" required>
  Token Bearer obtido no endpoint de autenticação ``` Bearer
  eyJhbGciOiJIUzI1NiIsInR5cCI6Ikp... ```
</ParamField>

## Parâmetros de Query

<ParamField query="page" type="integer" default="1">
  Número da página para paginação
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Quantidade de merchants por página (máximo: 100)
</ParamField>

<ParamField query="status" type="string">
  Filtrar por status: `ACTIVE`, `INACTIVE`, `SUSPENDED`
</ParamField>

<RequestExample>

```bash cURL
curl -X GET "https://api.pronttus.com.br/v1/merchants?page=1&limit=10" \
  -H "Authorization: Bearer seu_token"
```

```javascript JavaScript
const api = new PronttusAPI(clientId, clientSecret);

const response = await api.makeRequest(
  "https://api.pronttus.com.br/v1/merchants?page=1&limit=10",
  {
    method: "GET",
    headers: { "Content-Type": "application/json" }
  }
);

const data = await response.json();
```

```python Python
import requests

headers = {
    'Authorization': f'Bearer {token}',
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://api.pronttus.com.br/v1/merchants?page=1&limit=10',
    headers=headers
)

data = response.json()
```

</RequestExample>

</ResponseField>
